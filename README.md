# 오늘의 도서관 아카이브 (시연본)

국립중앙도서관 소식지 《오늘의 도서관》 Vol.293–346(2021년 6월호~2026년 10월호) 중 19개 호를 원문 근거로 찾아보는 AI 검색 아카이브 시연본입니다.

- 원문 출처: 국립중앙도서관 《오늘의 도서관》 (https://www.nl.go.kr/NL/contents/N50702000000.do)
- 《오늘의 도서관》은 공공누리 제4유형(출처표시·상업적 이용금지·변경금지) 조건으로 이용할 수 있으며, 일러스트레이션과 사진은 제외됩니다.
- 2021~2024년 일부 호와 2025년 3월호는 스캔본(외곽선 PDF)을 문자 인식한 텍스트라 오탈자가 있을 수 있습니다.
- 제안용 시연본이며 국립중앙도서관의 공식 서비스가 아닙니다.
